# Sistema de Clínica Veterinária Petlife 🐾

Projeto desenvolvido para a disciplina de **Programação Orientada a Objetos (POO)**. O sistema consiste em uma aplicação para gerenciamento de atendimentos, pacientes, tutores e serviços de uma clínica veterinária.

---

## 🎯 Objetivo do Projeto
Aplicar os principais conceitos do paradigma de Orientação a Objetos na construção de uma solução prática para o fluxo diário de uma clínica veterinária.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Java
* **Paradigma:** Orientação a Objetos
* **Ambiente de Desenvolvimento:** VS Code

## 🧩 Conceitos de POO Aplicados
* **Abstração:** Modelagem das entidades principais do domínio da clínica.
* **Encapsulamento:** Proteção do estado dos objetos com uso de atributos privados e métodos de acesso/modificação.
* **Herança:** Especialização de classes (ex: `Animal` $\rightarrow$ `Cachorro`, `Gato`; `Pessoa` $\rightarrow$ `Veterinario`, `Tutor`).
* **Polimorfismo:** Sobrescrita e sobrecarga de métodos (ex: cálculo de dosagem, cálculo do valor de consultas/procedimentos).

## 📋 Funcionalidades
* Cadastro e listagem de tutores e animais
* Registro e agendamento de consultas
* Emissão de diagnósticos e prescrições médicas
* Controle de serviços (vacinação, exames, internação)
* Relatórios gerais de atendimentos
